抢单助手 · 使用说明

Chrome 扩展 · 定时点击 · 自动提交订单，停在付款页

先说明边界：这是给你本人账号用的网页点击辅助工具。它不会绕过验证码、风控、排队或限购，不提供代拍/抢票/转售能力，也绝不会点击支付按钮。请确认目标网站允许此类辅助操作，账号受限或订单纠纷的风险由你自行承担。

1安装

  1. 打开 Chrome，地址栏输入 chrome://extensions 回车。
  2. 右上角打开「开发者模式」。
  3. 点「加载已解压的扩展程序」，选择本项目的 extension 文件夹。
  4. 把「抢单助手」固定到工具栏；打开商品页或结算页，点图标即可。

如果扩展刚安装时当前页面没有反应，刷新一次页面即可。

2录制步骤

  1. 先在 Chrome 里正常登录目标网站，走到你要开始抢的页面（例如商品详情页）。
  2. 点扩展图标 →「开始录制」。页面底部会出现黑色悬浮条。
  3. 按你真实下单的顺序点击：「立即购买」→「提交订单」。每点一步，悬浮条上的数字会加一。
  4. 点击「提交订单」时，扩展会记录这一步，但会拦截真实提交，不会在录制阶段产生订单。
  5. 点悬浮条的「完成」。回到扩展，你会看到步骤列表。
录制时页面跳转是正常的：跳转后悬浮条会重新出现，继续点下一步即可。支付按钮（去支付/立即支付/收银台）不会被记录，也不会被执行。
页面有多个步骤时，建议先点「检查步骤」。它只检查当前页面能匹配到的步骤，不会真的点击；跳转后的步骤需要到对应页面再检查。

3设置时间并布防

  1. 在「执行时间」里选择目标时间，精确到毫秒；也可以用「+10 秒」等快捷按钮做演练。
  2. 第一次使用建议点「校准网络时间」。扩展会对比网络时间并显示偏差；校准失败时会退回本机时钟。
  3. 点「布防 · 定时执行」。扩展会在目标时间前约 20 秒切回录制页面、准备计时器。
  4. 到点后自动执行第一步，后续步骤按页面跳转依次执行；最后一步是「提交订单」。
  5. 看到「已提交」后，立即回到页面检查订单并手动付款。
执行期间请保持电脑唤醒、目标页面打开，尽量不要切换标签页或手动点击，避免和扩展争抢页面状态。

4它不会做什么

能力说明
绕过验证码/滑块不会。检测到验证会暂停并通知你手动完成。
自动付款不会。到「提交订单」为止，付款由你操作。
多账号/多订单不会。一次布防只执行一遍，不循环、不批量。
破解排队/风控不会。排队或风控页面只会等待或失败，不会伪造请求。
云端运行不会。所有步骤只保存在你本机 Chrome 的扩展存储里。

5常见问题

提示「未找到某一步」怎么办？

通常是页面改版、按钮文字变了，或者这一步其实在下一页。重新录制这一步即可；也可以先在对应页面点「检查步骤」确认能匹配到。

为什么到点没有执行？

检查目标页面是否被关闭、刷新或跳到了别的网址；检查是否锁屏；检查扩展是否被浏览器禁用。执行前约 20 秒扩展会尝试切回录制页面，若页面被关闭会重新打开。

提示「需要人工处理」怎么办？

页面出现了验证码、滑块或安全验证。请在弹出的页面里手动完成，然后回到扩展点「继续执行」。扩展不会替你破解验证。

会不会重复下单？

一次布防只执行一遍，最后一步执行完就停止，不会循环。但如果你手动刷新页面或再次点布防，可能产生新订单，请自己确认页面状态。

为什么不做成微信小程序？

微信小程序运行在微信沙箱里，无法读取或点击你 Chrome 里已登录的购物网页。要复用你的登录状态，浏览器扩展是唯一稳妥的形态。

支持所有购物/票务网站吗？

采用「录制点击」的通用方式，大多数普通网页可用。但每个网站的结算流程、验证码和风控不同；强验证或强排队的平台，只能做到「帮你点到提交订单」，不能保证抢到。

6安全建议

  • 不要录密码、支付密码、短信验证码；扩展默认不记录输入内容。
  • 不要把扩展文件夹发给别人；步骤里可能包含你的页面地址和按钮信息。
  • 只在自己常用的电脑和本人账号上使用。
  • 抢票/抢购前先用「+10 秒」做一次完整演练，确认每一步都能被找到。
